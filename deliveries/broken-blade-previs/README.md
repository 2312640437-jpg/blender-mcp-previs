# Broken Blade Messenger — previs delivery

Download `broken_blade_delivery.zip` using GitHub's **Download raw file** button (or the Raw link). Extract it locally.

The archive contains:

- `broken_blade_previs.mp4`: silent, 15 seconds, 1920×1080, 24 fps, H.264; shot labels included.
- `broken_blade_previs.blend`: editable Blender 4.3.2 scene.
- `previs_overview.jpg`: nine-shot contact sheet.
- `previs_notes.md`: character colors, shot timing, camera movements and limitations.
- `build.py`: scene generation script for the cloud workspace.

Messenger: orange. Main attacker: dark blue. Ambusher A: purple. Ambusher B: cyan.
The main attacker performs the combat in shots 02–06. Ambushers A and B appear only in shot 09 (14–15 seconds).

The MP4 has been checked for 360 decoded frames, 24 fps, 15 seconds, and H.264 playback. Audio and detailed performance are outside this previs delivery.
